# Уровень 2: Конкретные практики

## Практики

1. **«Сенсорное бюджетирование»** — планирование дня с учётом сенсорных затрат.

2. **«Создание среды поддержки»** — оборудование рабочего места для минимизации перегрузки.

3. **«Сенсорные перерывы»** — запланированные паузы между интенсивными стимулами.

4. **«Коммуникация о потребностях»** — разговоры с близкими о сенсорных границах.
