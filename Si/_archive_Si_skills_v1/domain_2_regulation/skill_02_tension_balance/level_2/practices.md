# Уровень 2: Конкретные практики

## Практики

1. **«Метод Pomodoro с телесной адаптацией»** — интервалы работы/отдыха подбираются индивидуально (например, 50/10 или 90/20), отслеживается телесный отклик.

2. **«Неделя отслеживания энергии»** — каждый час оценка уровня энергии по 10-балльной шкале.

3. **«План дня на основе циклов»** — планирование самых энергоёмких задач на пики, восстановительных — на спады.
