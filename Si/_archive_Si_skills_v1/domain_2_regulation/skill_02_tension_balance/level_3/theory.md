# Уровень 3: Психологический баланс через телесный ритм

## Суть

Дисбаланс «напряжение–расслабление» рассматривается как соматический симптом внутреннего психологического нарушения (например, неспособность отдыхать — страх потери контроля; хроническая апатия — выученная беспомощность). Телесная регуляция становится инструментом психологической коррекции.
