# Уровень 2: Действия ученика

## Что делает ученик

- Разрабатывает «карту уюта» для каждой зоны: какая там должна быть освещённость (ватты/кельвины), текстуры (дерево, шерсть, мягкий ковёр), запахи (ароматические палочки, свечи), звуки (фонтана, музыки).
- Создаёт ритуалы входа в дом/выхода: переодевание в домашнюю одежду, включание определённой музыки.
- Обеспечивает тактильное разнообразие: пледы разной фактуры, ковры, подушки.
- Поддерживает порядок на уровне «достаточно хорошо» (не музей, а жилое пространство).
