# Уровень 1: Критерии освоения и типичные ошибки

## Критерии освоения

- Ученик может описать 3–4 ключевых сенсорных параметра, формирующих атмосферу помещения.
- Проведено минимум 3 успешных изменения, одобренных домочадцами.

## Переход на следующий уровень

Среда целенаправленно проектируется под конкретные виды деятельности и потребности обитателей.
