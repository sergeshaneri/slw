# Уровень 1: Критерии освоения и типичные ошибки

## Критерии освоения

- Ученик выполняет ежедневные гигиенические ритуалы осознанно, может описать свои типичные ощущения.
- Проведены минимум 3 разные мягкие очистительные процедуры с записью ощущений.
- Отсутствуют экстремальные решения (строгое голодание без подготовки, постоянные клизмы).

## Типичные ошибки

- Игнорирование сигналов дискомфорта («так надо, терплю»).
- Копирование чужого опыта без учёта индивидуальных реакций.
- Слишком резкое начало (например, сухое голодание с нуля).

## Переход на следующий уровень

Накоплены данные о том, какие процедуры дают ресурсное состояние, а какие вызывают дискомфорт, появляется желание систематизировать очищение.
