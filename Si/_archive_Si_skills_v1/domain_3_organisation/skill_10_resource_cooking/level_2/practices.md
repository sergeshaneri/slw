# Уровень 2: Конкретные практики

## Практики

1. **«Импровизация с ограничениями»** — раз в неделю готовить блюдо из того, что есть в холодильнике, не пользуясь рецептом, тренируя интуицию.
2. **«Колесо вкусов»** — составить таблицу любимых продуктов, распределённых по вкусовым категориям (сладкие, кислые, солёные, горькие, умами), и экспериментировать с балансом.
3. **«Блюдо под состояние»** — перед готовкой определить желаемое состояние после еды (бодрость, тепло, лёгкость) и приготовить блюдо с этим намерением.
