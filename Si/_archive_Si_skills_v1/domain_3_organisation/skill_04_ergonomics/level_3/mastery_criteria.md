# Уровень 3: Критерии освоения и типичные ошибки

## Критерии освоения

- Пространство вызывает ощущение «я на своём месте».
- Ученик сознательно меняет элементы среды для регуляции состояния (например, при тревоге зажигает определённую свечу) и отмечает эффект.
- Процесс организации пространства перестаёт быть обузой и становится формой самозаботы.
