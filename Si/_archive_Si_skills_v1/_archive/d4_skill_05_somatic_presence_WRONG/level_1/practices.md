# Уровень 1: Конкретные практики

## Практики

1. **«Замечание вылета»** — осознание ухода в мысли.

2. **«Телесный якорь»** — использование дыхания, стоп, осанки для возвращения.

3. **«Микро-присутствие»** — короткие моменты осознанности в течение дня.

4. **«Мягкое возвращение»** — без осуждения, с принятием.
