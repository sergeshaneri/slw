# Уровень 3: Конкретные практики

## Практики

1. **«Переименование»** — изменение смысла через новое название.

2. **«Новый нарратив»** — создание новой истории о теле и опыте.

3. **«Соматические аффирмации»** — утверждения, ориентированные на тело.

4. **«Работа с критиком»** — изменение внутреннего диалога.

5. **«Переписывание травмы»** — трансформация травматического опыта через язык.
