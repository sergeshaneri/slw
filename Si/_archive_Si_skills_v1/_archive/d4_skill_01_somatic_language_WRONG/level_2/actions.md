# Уровень 2: Действия ученика

## Что делает ученик

- Находит метафоры для ощущений («камень в желудке», «бабочки в животе»).
- Использует образы из природы, животных, стихий.
- Практикует «поэтическое описание» ощущений.
- Ведёт диалог с частями тела, используя их «голос».
- Слушает метафоры других и улавливает их соматический смысл.
