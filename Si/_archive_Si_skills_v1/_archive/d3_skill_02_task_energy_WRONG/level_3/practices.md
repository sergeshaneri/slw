# Уровень 3: Конкретные практики

## Практики

1. **«Исследование сопротивления»** — понимание, почему задача отнимает энергию.

2. **«Поиск смысла»** — создание или обнаружение значимости в любой задаче.

3. **«Осознанное выполнение»** — изменение качества внимания к «вампирам».

4. **«Трансформация отношения»** — работа с внутренним контекстом задачи.
