# Уровень 3: Конкретные практики

## Практики

1. **«Движущаяся медитация»** — движение как форма осознанности.

2. **«Танец как искусство»** — творческое самовыражение через движение.

3. **«Движение как молитва»** — духовное соединение через тело.

4. **«Движение в природе»** — интеграция с миром через движение.

5. **«Встроенное движение»** — движение как естественная часть жизни.
