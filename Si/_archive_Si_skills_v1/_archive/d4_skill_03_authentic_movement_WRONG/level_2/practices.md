# Уровень 2: Конкретные практики

## Практики

1. **«Движение эмоций»** — проживание чувств через движение.

2. **«Двигательный словарь»** — развитие персонального языка движения.

3. **«Внутренний фокус»** — внимание к ощущениям, а не внешнему виду.

4. **«Восстановительные движения»** — поиск движений, дающих ресурс.

5. **«Музыкальное движение»** — движение под музыку, резонирующую с состоянием.
