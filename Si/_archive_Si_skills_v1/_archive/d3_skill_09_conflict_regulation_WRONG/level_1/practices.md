# Уровень 1: Конкретные практики

## Практики

1. **«Карта ранних сигналов»** — определение персональных признаков конфликтной активации.

2. **«Стоп-кадр»** — пауза при первых признаках напряжения.

3. **«Заземление в конфликте»** — простая техника для снижения активации.

4. **«Просьба о паузе»** — осознанный запрос времени для регуляции.
