# Уровень 2: Действия ученика

## Что делает ученик

- Использует дыхание для поддержания «окна толерантности».
- Следит за осанкой — не сжиматься, не «атаковать» позой.
- Различает свою реакцию и действительное намерение другого.
- Может выражать гнев/фрустрацию конструктивно.
- Использует телесные техники для восстановления после конфликта.
