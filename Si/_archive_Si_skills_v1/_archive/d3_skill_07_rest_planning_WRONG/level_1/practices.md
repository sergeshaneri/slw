# Уровень 1: Конкретные практики

## Практики

1. **«Отдых в календаре»** — бронирование времени для восстановления.

2. **«Типы отдыха»** — разные формы под разные потребности.

3. **«Дневник отдыха»** — отслеживание, что действительно восстанавливает.

4. **«Защита границ»** — отстаивание запланированного отдыха.
