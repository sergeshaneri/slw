# Уровень 3: Конкретные практики

## Практики

1. **«Чтение поля»** — глубокое восприятие групповой динамики.

2. **«Заземляющее присутствие»** — служение стабильным центром для группы.

3. **«Исцеление поля»** — использование присутствия для трансформации группы.

4. **«Аутентичность как разрешение»** — дар свободы быть собой другим.

5. **«Духовная устойчивость»** — интеграция социальной чувствительности и внутренней силы.
