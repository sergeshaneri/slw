# Уровень 3: Конкретные практики

## Практики

1. **«Портал в flow»** — расширенный ритуал для входа в потоковое состояние.

2. **«Церемония начала»** — символический акт начала важного проекта.

3. **«Телесное вызывание»** — использование движения и звука для изменения состояния.

4. **«Ритуал как искусство»** — превращение ритуала в творческий акт.
