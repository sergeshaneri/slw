# Уровень 3: Действия ученика

## Что делает ученик

- Использует длительные ритуалы для входа в глубокие состояния (flow).
- Создаёт персональные церемонии начала важных проектов.
- Интегрирует движение, дыхание, звук для изменения состояния.
- Работает с энергией «вызова» или «приглашения» нужного состояния.
