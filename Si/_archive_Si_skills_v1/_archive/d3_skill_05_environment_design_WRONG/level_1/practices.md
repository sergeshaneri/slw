# Уровень 1: Конкретные практики

## Практики

1. **«Сенсорный аудит»** — оценка пространства по 5 сенсорным каналам.

2. **«Карта раздражителей»** — выявление элементов, истощающих энергию.

3. **«Карта поддержки»** — выявление элементов, дающих ресурс.

4. **«Минимальные изменения»** — одно удаление раздражителя, одно добавление комфорта.
