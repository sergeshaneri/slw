# Уровень 3: Конкретные практики

## Практики

1. **«Соматический маятник»** — осознанное переключение между напряжением и расслаблением.

2. **«Длительное заземление»** — удержание контакта с телом в течение 20–30 минут.

3. **«Заземление при флешбэке»** — техники возвращения в настоящий момент при травматических воспоминаниях.
