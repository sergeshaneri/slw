# Уровень 3: Заземление как доступ к ресурсному состоянию при травме

## Суть

В ситуациях, когда человек «вылетает» из тела (диссоциация, флешбэк), заземление становится мостом к безопасности. Ученик осваивает длительное удержание контакта с телом для переработки травматического опыта (под наблюдением терапевта).
