# Уровень 3: Действия ученика

## Что делает ученик

- Практикует «Сканирование эмоций» — при возникновении любой эмоции сразу искать её в теле.
- Работает с картой телесных ощущений эмоций.
- Использует техники майндфулнес для углубления интероцептивной осведомлённости.
- Признаёт ранние сигналы диссоциации и использует техники заземления.
