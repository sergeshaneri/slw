# Уровень 2: Конкретные практики

## Практики

1. **«Сенсорный профиль домочадца»** — заполняется совместно с самим человеком, что даёт ему возможность осознать свои предпочтения.
2. **«Совет по уюту»** — раз в месяц семья обсуждает, что можно улучшить в общем пространстве для комфорта каждого.
3. **«День заботы без слов»** — один день ученик старается предугадать потребности близких и удовлетворить их до того, как они попросят.
