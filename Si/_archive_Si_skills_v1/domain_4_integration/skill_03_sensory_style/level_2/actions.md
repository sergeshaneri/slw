# Уровень 2: Действия ученика

## Что делает ученик

- Определяет 2–3 ключевые стилевые концепции, которые резонируют с самоощущением (например, «спокойный минимализм», «творческий бохо»).
- Составляет капсульный гардероб из взаимозаменяемых вещей, где каждая деталь прошла проверку на тактильный комфорт и эстетическую гармонию.
- Учится подбирать аксессуары, причёску, аромат так, чтобы они дополняли образ, а не конфликтовали.
- Экспериментирует с цветовыми палитрами, которые усиливают настроение (тёплые оттенки для энергии, холодные для сосредоточенности).
