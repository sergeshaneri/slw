# Практика: Улучшение Окружения

## Задание

Сделайте **3 маленьких улучшения** в своём пространстве для повышения комфорта.

## Идеи улучшений

### Дом/Квартира
- [ ] Купить мягкий плед
- [ ] Добавить ароматическую свечу или диффузор
- [ ] Повесить шторы блэкаут для лучшего сна
- [ ] Купить удобную подушку
- [ ] Разобрать один «захламлённый уголок»

### Рабочее место
- [ ] Настроить освещение (мягкий свет)
- [ ] Добавить растение
- [ ] Организовать кабели
- [ ] Поставить удобную подставку под ноутбук

### Одежда
- [ ] Выбросить вещи, которые дискомфортируют
- [ ] Купить одну качественную вещь из приятной ткани

### Питание
- [ ] Купить качественный чай/кофе
- [ ] Приготовить один «особенный» ужин
- [ ] Попробовать новый фрукт/овощ

---

**Важно:** Не пытайтесь сделать всё идеально. Маленькие шаги — ключ к успеху.
