# Упражнение: Диалог с Телом — Продвинутый Уровень

## Методика

Трижды в день (утром, днём, вечером) уделите 2-3 минуты «разговору» с телом.

### Вопросы для тела:

**Утро:**
- «Как ты себя чувствуешь сегодня?»
- «Что тебе нужно для хорошего дня?»
- «Где есть напряжение, которое я могу снять?»

**День:**
- «Ты устал(о)?»
- «Что ты чувствуешь прямо сейчас?»
- «Что тебе нужно в этот момент?»

**Вечер:**
- «Что было хорошего сегодня?»
- «Что было сложного?»
- «Что тебе нужно для восстановления?»

### Как «слушать» ответы:
- Не думайте логически — чувствуйте
- Первый импульс — часто ответ тела
- Записывайте инсайты в дневник

## Цель
Выстроить регулярный, доверительный контакт с телом.
