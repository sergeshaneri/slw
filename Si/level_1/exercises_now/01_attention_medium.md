# Упражнение: Сканирование Тела (Body Scan)

## Методика

Лежа или сидя, медленно проводите луч своего внимания по всему телу, от кончиков пальцев ног до макушки.

### Порядок сканирования:
1. Пальцы ног → стопы → лодыжки
2. Икры → колени → бёдра
3. Таз → поясница → живот → грудная клетка
4. Пальцы рук → ладони → запястья → предплечья → плечи
5. Шея → челюсть → лицо → лоб → макушка

### Что отмечать:
- Тепло / холод
- Покалывание
- Напряжение / расслабление
- Тяжесть / лёгкость
- Любые другие ощущения

### Важно:
- Без оценки («хорошо/плохо»)
- Просто замечайте
- 5-10 минут в день
- Лучше всего перед сном

## Цель
Развить глубокую связь с телом и умение «слышать» его сигналы.
