# Цель Уровня 0 по БС

## Чего достичь на этом уровне:

1. ✅ Начать замечать телесные ощущения (приятные и неприятные)
2. ✅ Начать вести «Дневник Ощущений»
3. ✅ Составить первичную карту своей БС
4. ✅ Научиться задавать телу простые вопросы
5. ✅ Осознать влияние окружения на комфорт

**Переход на Уровень 1:** когда пройдены все задания уровня 0 и ведётся дневник минимум 3 дня.
