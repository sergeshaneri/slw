#### Критерии БС
- **Визуально:** цвета, порядок, красота
- **На ощупь:** текстуры, температуры, мягкость
- **Звук:** тишина, приятные звуки, изоляция от шума
- **Запах:** чистота, ароматы, свежесть
- **Функционально:** удобство, эргономика, доступность

## План улучшений

### Быстрые победы (сделать за неделю)
- [ ] Убрать один захламлённый угол
- [ ] Добавить источник приятного запаха
- [ ] Повесить шторы блэкаут (спальня)
- [ ] Купить мягкий плед
- [ ] Организовать освещение (мягкий свет)

### Средние проекты (месяц)
- [ ] Обновить постельное бельё (качественное)
- [ ] Разобрать гардероб (оставить только комфортное)
- [ ] Создать «зону релаксации»
- [ ] Улучшить рабочее место (эргономика)

### Большие проекты (3-6 месяцев)
- [ ] Ремонт/обновление одной комнаты
- [ ] Покупка качественной мебели
- [ ] Создание домашнего СПА (джакузи, сауна)

## Бюджет и приоритеты

**Правило:** Лучше один качественный предмет, чем много дешёвых.

**Приоритеты по влиянию на комфорт:**
1. Сон (матрас, подушка, шторы)
2. Одежда (ткани, которые носите ежедневно)
3. Рабочее место (стул, стол, свет)
4. Общий уют (пледы, свечи, растения)
