# Уровень 2: Конкретные практики

## Практики

1. **«Зонирование пространства»** — разные места для разных активностей.

2. **«Эргономическая инвестиция»** — оборудование, заботящееся о теле.

3. **«Контроль сенсорного фона»** — управление шумом, светом, температурой.

4. **«Среда поддержки»** — создание пространства самозаботы.

5. **«Сезонная корректировка»** — адаптация под изменения потребностей.
