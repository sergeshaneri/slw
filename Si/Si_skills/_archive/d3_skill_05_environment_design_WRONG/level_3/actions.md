# Уровень 3: Действия ученика

## Что делает ученик

- Наполняет пространство символами, напоминающими о ценностях и целях.
- Создаёт «места силы» — пространства для глубокой работы и восстановления.
- Использует среду для поддержания фокуса на долгосрочных целях.
- Создаёт красоту и гармонию как форму самовыражения.
- Регулярно очищает и обновляет пространство, отражая внутренние изменения.
