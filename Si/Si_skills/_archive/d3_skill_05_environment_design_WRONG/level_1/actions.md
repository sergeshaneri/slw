# Уровень 1: Действия ученика

## Что делает ученик

- Проводит аудит рабочего и домашнего пространства с точки зрения тела.
- Замечает, какие элементы среды раздражают или истощают (шум, неудобный стул).
- Замечает, какие элементы поддерживают (тепло, свет, уют).
- Делает минимальные изменения: убирает один раздражитель, добавляет один комфорт.
