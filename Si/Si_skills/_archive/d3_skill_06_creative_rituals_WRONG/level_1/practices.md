# Уровень 1: Конкретные практики

## Практики

1. **«Музыкальный якорь»** — определённая музыка для входа в творческий режим.

2. **«Телесный триггер»** — поза, жест или движение для переключения.

3. **«Предмет-якорь»** — специальный предмет, ассоциированный с творчеством.

4. **«Мини-ритуал»** — короткая церемония (чай, свеча, дыхание).
