# Уровень 1: Критерии освоения

## Критерии

- Ритуал используется регулярно в течение 2 недель.
- Замечается облегчение входа в творческий режим.
- Может преодолеть сопротивление началу с помощью ритуала.

## Переход на следующий уровень

Начинает различать ритуалы для разных типов творческой работы.
