# Уровень 2: Конкретные практики

## Практики

1. **«Дыхательный сброс»** — 3 минуты дыхания для обнуления.

2. **«Физическая разрядка»** — движение для сброса накопленного состояния.

3. **«Заземление в новом контексте»** — техники присутствия при входе.

4. **«Пространственные зоны»** — разные физические места для разных ролей.
