# Уровень 1: Конкретные практики

## Практики

1. **«Смена одежды»** — физический разделитель между контекстами.

2. **«Пауза на пороге»** — остановка перед входом в новое пространство.

3. **«Осознание перетаскивания»** — замечание, что несём состояние из другого контекста.

4. **«Физическое перемещение»** — прогулка, проезд как разделитель.
