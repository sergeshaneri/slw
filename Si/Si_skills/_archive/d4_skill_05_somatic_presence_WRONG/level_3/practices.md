# Уровень 3: Конкретные практики

## Практики

1. **«Непрерывное присутствие»** — соматическое осознание как норма.

2. **«Тело как канал»** — открытость восприятию через тело.

3. **«Естественное состояние»** — присутствие без усилий.

4. **«Полное здесь»** — возможность быть здесь в любой ситуации.

5. **«Интегрированное присутствие»** — сочетание с действием и мышлением.
