# Уровень 2: Действия ученика

## Что делает ученик

- Создаёт разные ритуалы для разных типов активности (творческое, аналитическое, рутинное).
- Использует разную осанку, дыхание, пространство для разных задач.
- Привязывает ритуалы к помодоро или другим временным блокам.
- Закрывает рабочие блоки ритуалом завершения.
