# Уровень 1: Конкретные практики

## Практики

1. **«Сигнал начала»** — выбор и закрепление телесного якоря для работы.

2. **«Повторение»** — регулярное использование якоря в течение 2 недель.

3. **«Наблюдение за conditioning»** — замечание, как тело начинает реагировать на якорь.

4. **«Якорь возврата»** — использование ритуала для возврата фокуса.
