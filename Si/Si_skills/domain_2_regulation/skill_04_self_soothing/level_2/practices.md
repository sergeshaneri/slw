# Уровень 2: Конкретные практики

## Практики

1. **«Аптечка самоуспокоения»** — физический набор предметов для самоуспокоения.

2. **«Карта техник»** — соответствие техник типам эмоций и контекстам.

3. **«Профилактическое самоуспокоение»** — регулярные микро-практики для поддержания баланса.

4. **«Адаптация под контекст»** — версии техник для публичных мест.
