# Уровень 1: Конкретные практики

## Практики

1. **«Микро-отдых»** — 10 минут лёжа с закрытыми глазами.

2. **«Воздушная пауза»** — короткая прогулка на свежем воздухе.

3. **«Питательный перекус»** — осознанное питание для восстановления энергии.

4. **«Планирование отдыха»** — включение времени на восстановление в расписание.
