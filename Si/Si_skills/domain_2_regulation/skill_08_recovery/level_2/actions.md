# Уровень 2: Действия ученика

## Что делает ученик

- Диагностирует тип усталости по сенсорным и эмоциональным маркерам.
- Применяет специфическое восстановление: физическая усталость — растяжка/сон, ментальная — переключение активности, эмоциональная — самоуспокоение.
- Создаёт «меню восстановления» с опциями для разных состояний.
- Отслеживает эффективность разных техник.
