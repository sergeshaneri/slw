# Уровень 2: Критерии освоения

## Критерии

- Может «продышать» эмоцию, используя тело.
- Замечает трансформацию эмоции при телесной работе.
- Использует тело для снижения интенсивности эмоции без подавления.

## Переход на следующий уровень

Эмоции становятся материалом для глубинной работы и роста.
