# Уровень 1: Действия ученика

## Что делает ученик

- Составляет список всех отложенных медицинских дел, начиная с самого простого или самого важного, и каждую неделю закрывает один пункт (звонок, запись, визит).
- При возникновении боли или непривычного ощущения фиксирует его длительность (более 2–3 дней без тенденции к улучшению — повод для визита), интенсивность, сопутствующие факторы.
- Раз в год проходит минимальный профилактический осмотр (терапевт, стоматолог, для женщин — гинеколог).
