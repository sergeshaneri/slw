# Уровень 1: Действия ученика

## Что делает ученик

- Разрабатывает минимальный график уборки: ежедневно (5–10 минут): заправить кровать, убрать посуду, протереть поверхности на кухне; еженедельно (30–60 минут): влажная уборка, пылесос, санузел.
- Использует принцип «верни на место» сразу после использования.
- Выделяет места для ключевых категорий вещей (ключи, документы, косметика) и придерживается их.
- При уборке старается замечать тактильные ощущения: чистая поверхность гладкая, пыль шершавая, запах чистящего средства.
