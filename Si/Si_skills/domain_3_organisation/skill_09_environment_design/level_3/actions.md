# Уровень 3: Действия ученика

## Что делает ученик

- Изучает принципы средовой терапии ( healing environments) и применяет их: доступ к природе (вид из окна, растения), естественные материалы, возможность уединения, контроль над стимулами.
- Создаёт дома «пространство восстановления» (уголок с креслом, пледом, дневником, свечой), куда любой член семьи может уйти для самовосстановления.
- В случае болезни или стресса близкого человека настраивает его комнату так, чтобы она способствовала выздоровлению: мягкий свет, доступ к воде, приятные текстуры, отсутствие раздражающих звуков.
- Использует знание сенсорного программирования для общественных инициатив (помощь в оформлении офиса НКО, благоустройство двора), неся гармонию в более широкий круг.
