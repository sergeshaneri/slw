# Уровень 3: Критерии освоения и типичные ошибки

## Критерии освоения

- Пространство, созданное учеником, оказывает выраженное положительное влияние на самочувствие.
- Ученик способен консультировать других по организации комфортной среды (на бытовом уровне).
- Среда становится незаметным «помощником» в повседневной жизни.

## Типичные ошибки

- Перфекционизм, стремление к «идеальному» дому, вызывающее тревогу при любых нарушениях порядка.
- Навязывание своего видения комфорта без учёта обратной связи.
