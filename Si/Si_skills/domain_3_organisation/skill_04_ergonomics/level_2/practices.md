# Уровень 2: Конкретные практики

## Практики

1. **«Зонирование по действиям»** — план квартиры с выделением трёх обязательных зон.
2. **«Дневник пространственных переходов»** — запись эффективности работы/отдыха в разных точках для нахождения оптимальных.
3. **«Эксперимент с освещением»** — смена температуры света в течение дня (утро — холодный, вечер — тёплый).
