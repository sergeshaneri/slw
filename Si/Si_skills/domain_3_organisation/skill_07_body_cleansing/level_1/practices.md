# Уровень 1: Конкретные практики

## Практики

1. **«Дневник гигиенического внимания»** — в течение 3 дней ученик записывает каждое гигиеническое действие и ощущения до/после (например, «умывание прохладной водой — бодрость в лице, ясность»).
2. **«Мягкая чистка выходного дня»** — раз в 1–2 недели выбирается день, когда ученик ест только лёгкую растительную пищу или пьёт воду/травяные чаи, и наблюдает за реакциями тела.
3. **«Банный эксперимент»** — посещение бани/сауны с обязательным ведением дневника: температура, длительность заходов, питьевой режим, ощущения после.
4. **«Гигиенический чек-лист»** — список ежедневных процедур, который выполняется осознанно.
