# Уровень 3: Конкретные практики

## Практики

1. **«Кулинарное послание»** — приготовить блюдо для конкретного человека, вложив в него определённое пожелание (силы, спокойствия, радости), и отследить реакцию.
2. **«Мой фирменный рецепт»** — создать блюдо, которое станет «визитной карточкой», отражающей индивидуальность.
3. **«Сезонный кулинарный альбом»** — в течение года собирать рецепты блюд, приготовленных из сезонных продуктов, с фотографиями и описанием ощущений, создавая личную книгу ресурсной кулинарии.
