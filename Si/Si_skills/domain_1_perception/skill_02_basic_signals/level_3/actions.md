# Уровень 3: Действия ученика

## Что делает ученик

- При повторяющихся или избыточных сигналах (неконтролируемый голод, необъяснимая усталость) проводит глубинное исследование: какие ситуации предшествуют, какие эмоции сопровождают, какой «вторичный выигрыш» даёт состояние.
- Использует техники работы с «внутренним ребёнком» и другими субличностями, чтобы выяснить, какую нужду на самом деле пытается закрыть тело.
- Проводит эксперименты с «насыщением» не через еду/сон, а через эмоциональное и творческое удовлетворение (например, вместо перекуса — разговор по душам, ведение дневника, творческое дело).
