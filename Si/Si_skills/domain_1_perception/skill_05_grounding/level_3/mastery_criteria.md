# Уровень 3: Критерии освоения

## Критерии

- Может использовать заземление для выхода из состояния диссоциации.
- Способен удерживать контакт с телом даже при сильном травматическом возбуждении.
- Работает с травматическим опытом под наблюдением терапевта.

## Типичные ошибки

- Попытка самостоятельной работы с травмой без профессиональной поддержки.
- Игнорирование сигналов перегрузки нервной системы.
