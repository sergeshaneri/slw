# Уровень 3: Действия ученика

## Что делает ученик

- Использует длительные сенсорные паузы (5–15 минут) для глубокого исследования.
- Применяет технику «наблюдения за наблюдателем» — осознание того, кто воспринимает.
- Интегрирует паузу в медитативную практику.
- Использует сенсорную паузу для доступа к креативным состояниям.
