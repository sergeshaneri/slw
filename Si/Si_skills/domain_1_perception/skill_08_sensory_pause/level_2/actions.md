# Уровень 2: Действия ученика

## Что делает ученик

- Использует сенсорную паузу при переключении между задачами.
- Делает паузу для снижения нарастающего напряжения.
- Применяет технику для восстановления внимания при рассеянности.
- Интегрирует паузы в рабочий процесс (помодоро с сенсорной паузой).
