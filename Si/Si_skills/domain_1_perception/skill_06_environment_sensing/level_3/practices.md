# Уровень 3: Конкретные практики

## Практики

1. **«Символический анализ пространства»** — исследование, как внутреннее состояние проецируется на организацию пространства.

2. **«Терапевтическая уборка»** — осознанное расхламление как работа с внутренним миром.

3. **«Создание места силы»** — формирование пространства с осознанно подобранными сенсорными стимулами для восстановления.
