# Уровень 3: Действия ученика

## Что делает ученик

- Живёт с непрерывным соматическим осознанием.
- Тело — открытый канал восприятия мира.
- Присутствие не требует усилий, это естественное состояние.
- Может быть полностью здесь в любой ситуации.
- Присутствие сочетается с действием, мышлением, творчеством.
