# Уровень 3: Действия ученика

## Что делает ученик

- Использует «переименование» для трансформации опыта («не страх, а возбуждение»).
- Создаёт новые нарративы о своём теле и опыте.
- Применяет аффирмации, ориентированные на тело.
- Работает с внутренним критиком, меняя его «речь».
- Использует язык для «переписывания» травматического опыта.
