# Уровень 1: Конкретные практики

## Практики

1. **«Сенсорный словарь»** — изучение и использование точных описаний.

2. **«Дневник открытий»** — сбор новых слов для ощущений.

3. **«Детальное описание»** — практика максимально подробного описания.

4. **«Замена общих слов»** — уточнение вагонных формулировок.
