# Уровень 2: Конкретные практики

## Практики

1. **«Соматические метафоры»** — поиск образов для ощущений.

2. **«Язык природы»** — использование образов стихий и животных.

3. **«Поэтическое описание»** — художественное выражение соматики.

4. **«Диалог частей»** — разговор с частями тела их «голосом».

5. **«Слушание метафор»** — улавливание соматического смысла чужих образов.
