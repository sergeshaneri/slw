# Уровень 3: Конкретные практики

## Практики

1. **«Глубинная интуиция»** — доверие соматическому знанию.

2. **«Творческие состояния»** — использование тела для доступа к креативности.

3. **«Очищение интуиции»** — различение истинной интуиции и проекций.

4. **«Мудрость для других»** — применение соматического интеллекта в помощи.

5. **「Целостное познание」 — объединение тела, ума и духа.
