# Уровень 3: Конкретные практики

## Практики

1. **«Осознанность в шуме»** — медитация в шумной обстановке, наблюдение за раздражением.

2. **«Заземление в сложных условиях»** — удержание контакта с телом при сильных стимулах.

3. **«Открытое внимание»** — практика позволять сенсорным данным проходить без цепляния.

4. **«Исследование чувствительности»** — работа с психологическими корнями сенсорной чувствительности.
