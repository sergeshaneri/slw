# Уровень 3: Действия ученика

## Что делает ученик

- Применяет осознанность к сенсорному дискомфорту: наблюдает раздражение без реакции.
- Использует техники заземления для удержания контакта с телом в шумной среде.
- Практикует «открытое внимание» — позволяет стимулам проходить через осознание без застревания.
- Работает с эмоциональным содержанием сенсорной чувствительности (часто связана с травмой).
