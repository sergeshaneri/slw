# Уровень 1: Конкретные практики

## Практики

1. **«Сигнал начала»** — ритуал начала работы (например, заваривание чая, настройка стола).

2. **«Сигнал окончания»** — ритуал завершения работы (например, закрытие ноутбука, фраза «Работа закончена»).

3. **«Переход к отдыху»** — ритуал переключения в режим восстановления.

4. **«Якорь внимания»** — физическое действие для возврата фокуса.
