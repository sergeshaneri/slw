# Уровень 3: Действия ученика

## Что делает ученик

- Наполняет ритуалы символическим содержанием (например, ритуал благодарности, ритуал отпускания).
- Создаёт ритуалы для важных жизненных переходов (начало проекта, окончание отношений).
- Использует ритуалы для интеграции опыта.
- Делится ритуалами с другими, создаёт семейные или групповые ритуалы.
