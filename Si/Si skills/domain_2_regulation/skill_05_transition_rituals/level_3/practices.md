# Уровень 3: Конкретные практики

## Практики

1. **«Символические ритуалы»** — ритуалы, выражающие ценности и намерения.

2. **«Ритуалы жизненных переходов»** — обозначение важных изменений в жизни.

3. **«Ритуалы интеграции»** — осмысление и впитывание опыта.

4. **«Коллективные ритуалы»** — создание общих ритуалов с близкими.
