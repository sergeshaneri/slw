# Уровень 2: Конкретные практики

## Практики

1. **«Диагностика типа усталости»** — определение характера истощения.

2. **«Меню восстановления»** — список техник для разных типов усталости.

3. **«Целевое восстановление»** — применение специфических техник под конкретный тип.

4. **«Аудит восстановления»** — отслеживание эффективности разных подходов.
