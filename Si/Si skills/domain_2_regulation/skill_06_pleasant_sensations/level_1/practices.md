# Уровень 1: Конкретные практики

## Практики

1. **«Дневник приятных ощущений»** — ежедневная запись 3 приятных сенсорных переживаний.

2. **«Сенсорная коллекция»** — собирание текстур, запахов, звуков, которые вызывают удовольствие.

3. **«Осознанное наслаждение»** — полное внимание к приятному сенсорному опыту без отвлечения.

4. **«Сенсорный перерыв»** — регулярное включение приятных ощущений в день.
