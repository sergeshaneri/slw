# Уровень 1: Критерии освоения

## Критерии

- Может назвать 10+ приятных сенсорных переживаний из собственного опыта.
- Есть физическая или записанная «коллекция» ресурсных стимулов.
- Регулярно включает приятные ощущения в повседневность.

## Переход на следующий уровень

Начинает использовать приятные ощущения для регуляции состояния.
