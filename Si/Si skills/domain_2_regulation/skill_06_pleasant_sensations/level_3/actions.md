# Уровень 3: Действия ученика

## Что делает ученик

- Практикует «благодарность через тело» — направление внимания на приятные ощущения как повод для благодарности.
- Использует сенсорные «якоря» для возврата к настоящему моменту.
- Разделяет приятные ощущения с другими, создавая коллективные моменты радости.
- Развивает способность находить приятное в простых, обыденных вещах.
