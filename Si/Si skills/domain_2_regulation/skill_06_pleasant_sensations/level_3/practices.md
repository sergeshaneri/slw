# Уровень 3: Конкретные практики

## Практики

1. **«Благодарность через тело»** — осознанное наслаждение как основа для благодарности.

2. **«Сенсорные якоря присутствия»** — использование ощущений для возврата в настоящее.

3. **«Коллективное наслаждение»** — разделение приятных ощущений с другими.

4. **«Простое чудо»** — способность находить приятное в обыденном.
