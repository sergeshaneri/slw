# Уровень 2: Конкретные практики

## Практики

1. **«Ресурсный first aid»** — быстрое обращение к любимым ощущениям при стрессе.

2. **«Среда поддержки»** — создание пространства с приятными сенсорными стимулами.

3. **«Сенсорная награда»** — использование приятных ощущений для закрепления достижений.

4. **«Таргетированные ресурсы»** — подбор ощущений под конкретные состояния.
