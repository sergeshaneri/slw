# Уровень 1: Конкретные практики

## Практики

1. **«Честное описание»** — объективное описание боли или дефицита без оценки.

2. **«Дневник симптомов»** — регулярная запись для выявления паттернов.

3. **«Противодействие катастрофизации»** — осознанный отказ от мыслей «всё пропало».

4. **«Медицинская консультация»** — обращение к профессионалам при необходимости.
