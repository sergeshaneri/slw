# Уровень 1: Действия ученика

## Что делает ученик

- При возникновении эмоции задаёт вопрос: «Где это в моём теле?»
- Фиксирует локализацию, размер, температуру, плотность эмоционального ощущения.
- Использует карты телесных ощущений эмоций для обучения.
- Не пытается сразу изменить или подавить — только замечает.
