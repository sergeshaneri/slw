# Уровень 1: Конкретные практики

## Практики

1. **«Сканирование эмоций»** — при каждой эмоции поиск её в теле.

2. **«Карта телесных эмоций»** — изучение типичных локализаций эмоций.

3. **«Описание ощущения»** — детальное описание физических характеристик эмоции.

4. **«Дневник эмоций в теле»** — регулярная запись соматических проявлений.
