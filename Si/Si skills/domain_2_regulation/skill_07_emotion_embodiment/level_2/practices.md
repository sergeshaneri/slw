# Уровень 2: Конкретные практики

## Практики

1. **«Дыхание в эмоцию»** — направление дыхания в зону телесного ощущения.

2. **«Микродвижения»** — разрешение телу выразить эмоцию через движение.

3. **«Звучание эмоции»** — использование голоса и звука для проживания.

4. **«Отслеживание трансформации»** — наблюдение за изменением качества ощущения.
