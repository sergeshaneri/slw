# Уровень 3: Действия ученика

## Что делает ученик

- Исследует историю и смысл постоянных эмоциональных паттернов через тело.
- Работает с травматическими эмоциями соматически, обеспечивая безопасность.
- Использует эмоции для принятия решений (интероцептивная мудрость).
- Развивает способность удерживать сложные эмоции через тело без диссоциации.
