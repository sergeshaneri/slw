# Уровень 3: Конкретные практики

## Практики

1. **«Соматическая терапия эмоций»** — глубинная работа с травматическими переживаниями.

2. **«Интероцептивная мудрость»** — использование телесных сигналов для принятия решений.

3. **«Удержание сложных эмоций»** — способность проживать сильные чувства без диссоциации.

4. **«Эмоции как проводники»** — исследование смысла и истории эмоциональных паттернов.
