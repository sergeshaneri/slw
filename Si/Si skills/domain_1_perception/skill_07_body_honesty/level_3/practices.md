# Уровень 3: Конкретные практики

## Практики

1. **«Генеалогия телесной лжи»** — исследование, откуда взялись паттерны игнорирования тела.

2. **«Переосмысление убеждений»** — работа с убеждениями, мешающими телесной честности.

3. **«Тело как компас»** — использование телесных сигналов для принятия важных решений.
