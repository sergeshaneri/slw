# Уровень 1: Конкретные практики

## Практики

1. **«Ноги на полу»** — сознательное давление стопами на пол, фокус на ощущении опоры.

2. **«Объятия бабочки»** — скрещивание рук на груди с попеременным постукиванием по плечам.

3. **«5-4-3-2-1»** — классическая техника заземления через органы чувств.
