# Уровень 2: Конкретные практики

## Практики

1. **«Триггер-заземление»** — привязка техники к конкретным звуковым/визуальным стимулам.

2. **«Протокол 3-3-3»** — 3 вдоха, 3 секунды на стопы, 3 хлопка в ладоши.

3. **«Утренняя заземлённость»** — ежедневная утренняя практика для установления контакта с телом.
