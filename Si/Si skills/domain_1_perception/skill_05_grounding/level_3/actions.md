# Уровень 3: Действия ученика

## Что делает ученик

- Использует расширенные практики соматического переживания (somatic experiencing).
- Работает с маятником между напряжением и расслаблением.
- При диссоциации осознанно удерживает контакт с телом через длительное время.
- При флешбэках использует заземление для возвращения в настоящий момент.
