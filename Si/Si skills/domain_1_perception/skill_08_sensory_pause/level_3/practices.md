# Уровень 3: Конкретные практики

## Практики

1. **«Глубокая сенсорная пауза»** — 10–15 минут полного присутствия в ощущениях.

2. **«Наблюдение за наблюдателем»** — исследование субъекта восприятия через паузу.

3. **«Креативная пауза»** — использование остановки для доступа к творческим состояниям.
