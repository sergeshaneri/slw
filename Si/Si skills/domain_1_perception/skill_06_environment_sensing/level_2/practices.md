# Уровень 2: Конкретные практики

## Практики

1. **«Сенсорный дизайн рабочего места»** — настройка освещения, звука, температуры под конкретную задачу.

2. **«Профиль активности»** — создание оптимальных сенсорных условий для разных типов деятельности.

3. **«Адаптация среды»** — активное изменение среды (включение/выключение света, открывание окна) для поддержания комфорта.
