# Уровень 3: Критерии освоения

## Критерии

- Может определить зарождающуюся эмоцию по телесным сигналам за 10–30 секунд до осознания.
- Эффективно использует интероцепцию для саморегуляции в стрессовых ситуациях.
- Может вернуться в «окно толерантности» при травматической активации.

## Типичные ошибки

- Переоценка телесных сигналов без учёта контекста.
- Игнорирование медицинских причин при интерпретации внутренних ощущений.
