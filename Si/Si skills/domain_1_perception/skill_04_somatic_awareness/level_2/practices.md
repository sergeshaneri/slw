# Уровень 2: Конкретные практики

## Практики

1. **«Дневник телесных решений»** — записи о решениях, принятых на основе внутренних ощущений, с проверкой результатов.

2. **«Шкала интероцепции»** — разработка собственной шкалы для разных типов внутренних ощущений.

3. **«Вопрос к телу»** — перед выбором: «Что чувствует моё тело при мысли о варианте А? О варианте Б?»
