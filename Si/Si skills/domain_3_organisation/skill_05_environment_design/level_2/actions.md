# Уровень 2: Действия ученика

## Что делает ученик

- Создаёт разные зоны для разных активностей (работа, отдых, творчество).
- Инвестирует в эргономику: стул, стол, освещение, монитор.
- Контролирует сенсорный фон: шумоподавление, освещение, температура.
- Создаёт «среду поддержки» — пространство, которое само заботится о нём.
- Регулярно корректирует среду по сезонам и изменениям потребностей.
