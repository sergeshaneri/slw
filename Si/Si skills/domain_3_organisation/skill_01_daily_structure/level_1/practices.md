# Уровень 1: Конкретные практики

## Практики

1. **«Три якоря»** — установка трёх фиксированных точек в дне.

2. **«Телесный таймер»** — привязка якорей к ощущениям, а не только времени.

3. **«Дневник ритма»** — отслеживание влияния структуры на самочувствие.

4. **«Вечерний аудит»** — оценка дня и корректировка завтрашних якорей.
