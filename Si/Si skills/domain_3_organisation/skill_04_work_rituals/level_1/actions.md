# Уровень 1: Действия ученика

## Что делает ученик

- Выбирает один простой телесный якорь для начала работы (постукивание по столу, глубокий вдох, фраза, осанка).
- Повторяет его каждый раз перед началом работы в течение 2 недель.
- Замечает, как тело начинает «готовиться» к ритуалу.
- Использует якорь также для возврата фокуса, если отвлёкся.
