# Уровень 1: Критерии освоения

## Критерии

- Якорь используется регулярно в течение 2 недель.
- Замечается телесная реакция на якорь (появляется готовность к работе).
- Может быстро вернуть фокус с помощью якоря.

## Переход на следующий уровень

Начинает создавать разные якоря под разные типы работы.
