# Уровень 2: Конкретные практики

## Практики

1. **«Меню отдыха»** — опции для разного времени и контекста.

2. **«Микро-перерывы»** — короткие паузы для профилактики.

3. **«Глубокий отдых»** — планирование полного восстановления.

4. **«Ритуалы отдыха»** — маркеры начала и окончания.

5. **«Баланс активности»** — сочетание активного и пассивного отдыха.
