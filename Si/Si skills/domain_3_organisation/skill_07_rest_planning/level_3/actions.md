# Уровень 3: Действия ученика

## Что делает ученик

- Использует отдых для интеграции опыта и развития.
- Создаёт «священные паузы» — время для глубокого присутствия.
- Наполняет отдых смыслом, красотой, радостью.
- Развивает «отдыхающее присутствие» — быть полностью в отдыхе.
- Отдых становится источником творчества и мудрости.
