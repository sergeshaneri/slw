# Уровень 3: Действия ученика

## Что делает ученик

- Использует расширенные ритуалы для входа в глубокое творческое состояние.
- Может вызывать состояние потока по намерению.
- Создаёт персональные церемонии для важных творческих проектов.
- Интегрирует движение, звук, пространство для создания «вибрации творчества».
- Ритуалы становятся священными актами, посвящёнными творчеству.
