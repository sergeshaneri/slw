# Уровень 2: Действия ученика

## Что делает ученик

- Создаёт разные ритуалы для разных фаз творческого процесса.
- Использует разные пространства или зоны для разных типов работы.
- Применяет разные дыхательные паттерны для разных состояний.
- Отслеживает, какие ритуалы работают лучше для каких задач.
