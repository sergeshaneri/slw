# Уровень 2: Действия ученика

## Что делает ученик

- Использует заземление и осанку для создания устойчивого присутствия.
- Сознательно «настраивает» своё состояние перед входом в группу.
- Может «заражать» группу позитивным состоянием (спокойствие, openness).
- Защищается от токсичного «заражения» через границы и заземление.
- Регулирует степень синхронизации — когда соединяться, когда сохранять автономию.
