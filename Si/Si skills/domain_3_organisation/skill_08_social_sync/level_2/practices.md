# Уровень 2: Конкретные практики

## Практики

1. **«Заземлённое присутствие»** — использование тела для создания устойчивости.

2. **«Настройка перед входом»** — предварительная установка состояния.

3. **«Позитивное заражение»** — намеренное влияние на энергию группы.

4. **«Защита границ»** — техники сохранения автономии.

5. **«Диалектика синхронизации»** — баланс между соединением и автономией.
