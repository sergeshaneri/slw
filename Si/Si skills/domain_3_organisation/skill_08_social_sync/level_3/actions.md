# Уровень 3: Действия ученика

## Что делает ученик

- Может «читать» социальное поле на глубоком уровне — напряжения, блоки, ресурсы.
- Служит «заземляющим элементом» для группы в сложных ситуациях.
- Использует своё присутствие для поддержки исцеления групповой динамики.
- Демонстрирует аутентичность, которая «разрешает» другим быть собой.
- Интегрирует социальную чувствительность с духовной устойчивостью.
