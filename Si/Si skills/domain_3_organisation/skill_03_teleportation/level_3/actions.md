# Уровень 3: Действия ученика

## Что делает ученик

- Использует каждый переход как практику осознанности.
- Привносит качества из одного контекста в другой осознанно (а не «перетаскивает»).
- Может быть полностью присутствующим в любом контексте без «остатков» другого.
- Превращает «переходы» в ценное время для себя.
