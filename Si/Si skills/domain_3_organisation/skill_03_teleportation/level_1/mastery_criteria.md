# Уровень 1: Критерии освоения

## Критерии

- Может назвать 3 ситуации «перетаскивания» за последнюю неделю.
- Использует хотя бы один разделитель регулярно.
- Замечает разницу, когда использует разделитель и когда нет.

## Переход на следующий уровень

Начинает создавать осознанные ритуалы перехода.
