# Уровень 2: Действия ученика

## Что делает ученик

- Создаёт «телепортационные ритуалы» для ключевых переходов (работа-дом, общественное-личное).
- Использует дыхание, движение, осознанность для «сброса» предыдущего контекста.
- Может быстро переключаться между ролями (работник, родитель, партнёр, сам с собой).
- Создаёт разные физические пространства или зоны для разных контекстов.
