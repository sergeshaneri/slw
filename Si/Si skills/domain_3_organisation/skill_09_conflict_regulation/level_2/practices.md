# Уровень 2: Конкретные практики

## Практики

1. **«Дыхание в окне»** — поддержание толерантности через дыхание.

2. **«Осознанная осанка»** — контроль позы в конфликте.

3. **«Разделение»** — отличие собственной реакции от намерения другого.

4. **«Конструктивное выражение»** — телесная поддержка при выражении сложных эмоций.

5. **«Восстановление»** — техники для снижения последствий конфликта.
