# Уровень 3: Конкретные практики

## Практики

1. **«Открытость в конфликте»** — любопытство вместо защиты.

2. **«Безопасное пространство»** — телесное создание контейнера для встречи.

3. **«Удержание интенсивности»** — способность быть с сильными эмоциями без диссоциации.

4. **«Конфликт как зеркало»** — использование противостояния для самопознания.

5. **«Углубление связи»** — трансформация конфликта в рост отношений.
