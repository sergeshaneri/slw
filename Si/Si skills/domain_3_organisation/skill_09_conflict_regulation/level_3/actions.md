# Уровень 3: Действия ученика

## Что делает ученик

- Сохраняет открытость и любопытство в конфликте.
- Использует тело для создания безопасного пространства встречи.
- Может «держать» интенсивность без диссоциации или агрессии.
- Видит конфликт как зеркало для самопознания.
- Использует конфликт для углубления отношений.
- Интегрирует духовные практики с работой в конфликтах.
