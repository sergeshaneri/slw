# Уровень 1: Конкретные практики

## Практики

1. **«Оценка перед»** — прогноз энергетического эффекта до начала задачи.

2. **«Фиксация после»** — запись фактического влияния на энергию.

3. **«Классификация задач»** — категоризация по энергетическому следу.

4. **«Дневник энергии задач»** — регулярная запись в течение недели.
