# Полярность Карта (Polarity Map) для Дилемм БС

## Инструмент работы с внутренними конфликтами

Полярность Карта помогает увидеть ценность ОБЕИХ сторон конфликта и найти «золотую середину».

---

## Шаблон карты

```
                    ┌─────────────────────────────────────┐
                    │        ОБЩАЯ ЦЕЛЬ                  │
                    │   (чего мы хотим достичь?)         │
                    └─────────────────────────────────────┘
                                    │
                    ┌───────────────┴───────────────┐
                    │                               │
                    ▼                               ▼
        ┌───────────────────────┐       ┌───────────────────────┐
        │    ПОЛЮС А (Тень)     │       │    ПОЛЮС Б (Дар)      │
        │                       │       │                       │
        │ Страхи:               │       │ Страхи:               │
        │ • ...                 │       │ • ...                 │
        │                       │       │                       │
        │ Желания:              │       │ Желания:              │
        │ • ...                 │       │ • ...                 │
        │                       │       │                       │
        │ Действия:             │       │ Действия:             │
        │ • ...                 │       │ • ...                 │
        │                       │       │                       │
        │ Результат в крайности │       │ Результат в крайности │
        │ • ...                 │       │ • ...                 │
        └───────────────────────┘       └───────────────────────┘
                    │                               │
                    └───────────────┬───────────────┘
                                    │
                    ┌───────────────▼───────────────┐
                    │      "БОЛЕЕ ВЫСОКАЯ ЦЕЛЬ"      │
                    │     (что объединяет оба полюса) │
                    └─────────────────────────────────┘
                                    │
                    ┌───────────────▼───────────────┐
                    │      "ИНТЕГРАЦИОННЫЕ          │
                    │       ДЕЙСТВИЯ"               │
                    │  (что включает оба полюса     │
                    │   в здоровом балансе)         │
                    └───────────────────────────────┘
```

## Пример: Дилемма «Наслаждение vs. Долг"

### Общая цель
Здоровое, удовлетворительное, устойчивое существование.

### Полюс А: Наслаждение (в крайности = Тень)
- **Страхи:** Усилие, боль, дискомфорт, лишение
- **Желания:** Расслабление, удовольствие, комфорт
- **Действия:** Прокрастинация, заедание, избегание
- **Результат в крайности:** Лень, гедонизм, стагнация

### Полюс Б: Долг/Дисциплина (в крайности = Тень)
- **Страхи:** Осуждение, провал, «лень»
- **Желания:** Успех, признание, контроль
- **Действия:** Насилие над собой, игнорирование сигналов
- **Результат в крайности:** Выгорание, отчуждение от тела

### Более высокая цель
Жизнь, наполненная и удовольствием, и достижениями — в балансе.

### Интеграционные действия
- Находить удовольствие в процессе (не только в результате)
- Делать «необходимое» комфортным
- Позволять себе отдых как часть достижения целей
- Выбирать «умные усилия» — эффективные и не разрушительные

---

## Применение

Заполните карту для вашей актуальной дилеммы БС:
- Наслаждение vs. Долг
- Слияние vs. Границы
- Перфекционизм vs. Принятие
