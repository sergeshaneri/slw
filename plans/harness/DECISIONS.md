# Принятые решения

| ID | Решение | Основание | Когда пересмотреть |
|---|---|---|---|
| DEC-001 | База lite — slw-instruct@c7f2b3c | Совпадает с origin после fetch; main имеет другую историю | При новых commits исходной ветки |
| DEC-002 | main/default branch не менять | Запрошена проверка; remote HEAD=gh-pages, затрагивается hosting workflow | При отдельной задаче нормализации Git |
| DEC-003 | Разделить bootstrap оболочек, переиспользовать UI/контент | App делает referral side effect при импорте; main запускает TMA | Если module graph выявит неустранимый общий эффект |
| DEC-004 | Чистое journey state выделить до изменения поведения | Defaults и миграции сейчас внутри JourneyView | После стабильного characterisation baseline |
| DEC-005 | Один атомарный lite-snapshot | Четыре записи из 001 допускают частично записанный импорт, rollback сам может упасть | Если размер требует IndexedDB |
| DEC-006 | Каталог имеет отдельную навигацию | Чтение не должно менять игровой курсор и начислять XP | Если пользователь отдельно попросит свободный игровой переход |
| DEC-007 | Временная версия не переписывает весь движок | Ограниченный срок использования; авторские тексты сохраняются | После отдельного аудита движка |
| DEC-008 | Harness — repo-файлы и проверка, без автоматики | Пользователь запросил план/правила/ошибки для улучшения процесса | Если понадобится CI после появления tests |
| DEC-009 | Новый запрос разрешает ветку и harness, не реализацию игры | Прямой объём запроса пользователя | При последующем указании реализовать план |

DEC-005 технически заменяет четырёхключевую схему 001. Поведенческие требования 001 остаются действующими. DEC-003 заменяет идею добавления всех lite-условий внутрь App: online App остаётся прежним, lite получает компактную отдельную оболочку без копирования игрового движка.

## DEC-010 — реализация разрешена

2026-09-11: прямое поручение пользователя разрешает P1–P7 плана 002, субагентов gpt-5.6-sol с reasoning effort medium и отдельные локальные коммиты после приёмки каждой задачи. DEC-009 описывает прежний контекст и заменён этим решением. Push, deploy, изменение main/default branch запрещены.
