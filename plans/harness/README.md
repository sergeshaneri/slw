## Запуск проверок harness

Из настоящего корня Git, PowerShell:
```powershell
& ./plans/harness/verify.ps1 -Mode Preparation -Typecheck
```

Preparation проверяет отсутствие изменений tracked-кода относительно базы. После начала реализации использовать `-Mode Docs`: проверяет ветку/базу, документы, граф этапов и защищённые файлы; изменения продукта не запрещает. Typecheck добавляет текущую проверку TypeScript из frontend. Скрипт не запускает install/build/deploy/fetch и не пишет журналы автоматически.

PASS этого скрипта означает только описанные проверки harness. Он не доказывает сетевую изоляцию или готовность lite. Результат команды и ограничения занести в RUN_LOG вручную. Для реализации нужны будущие unit/e2e-команды из плана.
