# Анкеты навыков ЧЛ · 62 навыка

Источник истины для skill-анкет аспекта ЧЛ. Vite импортирует этот файл
как сырой текст через `?raw`, парсер `parseScripts.js` раскручивает в
массив скриптов. Эти шаги НЕ попадают в L0-чат (`Te/l0.md`); они
доступны только через дерево навыков (`screen: 'skill-tree'`).

Каждый шаг — `kind: survey`, `skill: <id>` ссылается на анкету в
`skills/te-surveys.md` (когда будет написана). Реальный текст утверждений
(15 пунктов в 5 блоках) берётся из `SURVEYS[skillId]` в рантайме, тело
шага здесь — заглушка.

В L0-чате есть отдельные SURV-100..103 — первая оценка по 4 общим
базовым навыкам (см. `te-tree.js → COMMON_BASE_SKILLS`). Здесь —
все 58 архетипных + 4 общих повторно (для прохождения через дерево
с расширенной 15-пунктовой анкетой).
