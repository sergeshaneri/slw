# Анкеты навыков БС · 47 навыков

Источник истины для skill-анкет аспекта БС. Vite импортирует этот файл
как сырой текст через `?raw`, парсер `parseScripts.js` раскручивает в
массив скриптов. Эти шаги НЕ попадают в L0-чат (`bs-l0.md`); они
доступны только через дерево навыков (`screen: 'skill-tree'`).

Каждый шаг — `kind: survey`, `skill: <id>` ссылается на анкету в
`skills/surveys.md`. Реальный текст утверждений (15 пунктов в 5 блоках)
берётся из `SURVEYS[skillId]` в рантайме, тело шага здесь — заглушка.

История: 7 SURV-* удалены после слияний навыков (scan, relax, aging,
env-quality, env-design, load, library — см. `tree.js`). Нумерация
SURV-N оставлена с пропусками, чтобы не ломать `completedScripts`
у юзеров, которые уже взяли часть анкет. SURV-34..54 — 21 новый навык.
