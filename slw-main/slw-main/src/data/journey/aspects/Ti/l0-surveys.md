# Анкеты навыков БЛ · 41 навык

Источник истины для skill-анкет аспекта БЛ. Vite импортирует этот файл
как сырой текст через `?raw`, парсер `parseScripts.js` раскручивает в
массив скриптов. Эти шаги НЕ попадают в L0-чат (`Ti/l0.md`); они
доступны только через дерево навыков (`screen: 'skill-tree'`).

Каждый шаг — `kind: survey`, `skill: <id>` ссылается на анкету в
`skills/ti-surveys.md`. Реальный текст утверждений (15 пунктов в 5 блоках)
берётся из `TI_SURVEYS[skillId]` в рантайме, тело шага здесь — заглушка.

Доступ открывается после прохождения L0 БЛ (currentLevel >= 1) — анкеты
заполняют колесо БЛ реальной самооценкой по 4 архетипам (Аналитик,
Архитектор, Хранитель Порядка, Энциклопедист) перед L1.
