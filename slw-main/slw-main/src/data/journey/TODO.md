## Синхронизация числовых оценок L0/L1 с системой навыков БС

**Контекст.** На L0 есть 3 вопроса со шкалой 1–10 (B-1 «Качество сна», B-2 «Контакт с телом», B-3 «Тело — источник сигналов»). Сейчас они напрямую перезаписывают `scores.БС` — одно общее число.

После того, как пользователь начнёт проходить анкеты навыков (33 шт.), `calcBSScoreFromSkills` пересчитывает `scores.БС` через многоступенчатое усреднение и затирает старое значение из B-1.

**Что нужно сделать:**

1. Маппить B-вопросы L0 на конкретные навыки:
   - B-1 «Качество сна» → `sleep` (Хранитель)
   - B-2 «Контакт с телом» → `interoception` или `signals` (Целитель)
   - B-3 «Тень и Дар» → ?
2. После ответа на B-вопрос — записывать в `state.skills[skillId]` как «частичную» оценку (один блок? или среднюю по навыку без анкеты?).
3. При прохождении полной анкеты по тому же навыку — анкета перекрывает «частичную» оценку.

**Пока:** L0 числовые ответы → `scores.БС` напрямую (как было). Анкеты затирают это значение, как только пользователь начнёт их проходить.

**На L1 числовых вопросов нет** — все open-ended (формат B). Они уходят в дневник, не в scores.
