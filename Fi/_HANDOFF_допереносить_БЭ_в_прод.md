## 4. Технические инструкции

### Формат для каждого массива

**`professions`**, **`art`**, **`myths`**, **`childRaising`**, **`facts`** — массив объектов `{ name: '...', desc: '...' }`:
```js
{ name: '20. Психотерапевт зависимости (аддиктолог)', desc: 'Работает с людьми в зависимостях...' }
```

**`quotes`** — массив объектов `{ name: '...', desc: '...' }`:
```js
{ name: '«Цитата» — Автор', desc: 'Пояснение связи с навыком БЭ.' }
```

**`culturalDifferences`**, **`childhoodQuestions`** — массив строк:
```js
'Японская «амаэ» (甘え) — доверительная зависимость...'
```

**`historicalFigures`** — уже на 100%, не трогать.

### Где править

Один файл: `slw-main/slw-main/src/data/aspects-fi-extension.js`.

После каждого блока — собирать `npx vite build` для проверки.

### CONTENT_VERSION

После завершения Фазы 3 — бамп `CONTENT_VERSION` в `JourneyView.jsx` (текущий 23 → 24) с комментарием о доинтеграции.

### Размер файла-расширения

Сейчас `aspects-fi-extension.js` примерно 200 строк (после компактификации, которую я сделаю). После полного допереноса будет около **1500-2000 строк JS**. Это нормально — у Fe `aspects.js` блок длиннее.

### Использование исходного .md

В каждом .md уже готов структурированный контент. Большинство пунктов можно копировать **дословно** — только в JS-формате. Пример из `профессии БЭ.md`:

Исходник:
```md
### 18. Координатор работы с уязвимыми группами (бездомные, бывшие заключённые, ВИЧ+)

Работает с людьми, к которым общество относится с подозрением или презрением...
```

В JS:
```js
{ name: '18. Координатор работы с уязвимыми группами', desc: 'Работает с людьми, к которым общество относится с подозрением или презрением. Главное — относиться к подопечному как к человеку, не как к категории, и удерживать эту позицию в команде, которая склонна к выгоранию и цинизму. Ключевые навыки БЭ: Отделение Поступка от Личности, Защита Отсутствующего, Различение Жалости и Сострадания, Тёплая Дистанция.' },
```

## 5. Подсчёт объёма работы по приоритетам

### Приоритет 1 (критическое)
- Новый блок `facts`: ~90 пунктов = ~100 строк JS
- Профессии: ещё 90 пунктов = ~110 строк
- Искусство: ещё 84 пункта = ~100 строк
- Воспитание ребёнка: ещё 80 пунктов = ~95 строк

**Итого ~400 строк JS + один новый блок в `blocks.js`. Минимум 1 большой Write + 1 малый Edit.**

### Приоритет 2 (важное)
- Цитаты: ещё 60-65 пунктов = ~80 строк
- Мифы: ещё 30 пунктов = ~40 строк
- Культуры: ещё 33 пункта = ~40 строк
- Вопросы детства: ещё 30 пунктов = ~35 строк

**Итого ~200 строк JS. Один большой Write.**

### Приоритет 3 (опциональное)
- Расширение HALL_CONTENT.Fi: ~50-100 строк JS

**Итого ~50-100 строк. Один малый Edit.**

## 7. Принципы стилистики (важно сохранять)

- **БЭ-регистр**: чувствует, узнаёт, доверяет, бережёт, выбирает, держит верность, мостит, передаёт, чтит, отпускает.
- **Без БЛ-аналитизма**: не «анализирует», «формализует», «выводит».
- **Без ЧЭ-экспрессии**: не «зажигает», «заражает», «искрит».
- **С привязкой к навыкам**: где возможно, упоминать конкретные навыки БЭ из 58-навычного дерева (Установление Доверия, Глубокое Видение Другого, Зримая Забота, и т.д.).
- **С привязкой к архетипам**: 🌉 Дипломат, 🕊 Духовник, 🏛 Хранитель Рода, 🤝 Друг.
- **Психотерапевтические опоры**: упоминать (где уместно) Боулби, Эйнсуорт, Боуэна, Шутценбергер, Хеллингер, Нефф, Лауба, schema therapy, continuing bonds.
