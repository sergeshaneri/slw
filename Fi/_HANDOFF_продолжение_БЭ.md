**Тип защит, часто работающих на БЭ-навыки:**

## 4. Технические якоря

### Архетипы БЭ
- 🌉 **Дипломат** (diplomat) — мост между сторонами и средами. Цвет `#f4a6c0`.
- 🕊 **Духовник** (confessor) — принимающий чужое сокровенное. Цвет `#b794f4`.
- 🏛 **Хранитель Рода** (ancestor) — носитель связи поколений. Цвет `#d4a574`.
- 🤝 **Друг** (friend) — равная преданность. Цвет `#7dd3a8`.

### Тени архетипов (для теневого слоя)
- Дипломат → **Ублажающий** (теряет голос ради мира) // **Серый Кардинал** (манипулирует через мост)
- Духовник → **Инквизитор** (доверие → моральный суд) // **Святоша** (превосходство через «духовность»)
- Хранитель Рода → **Цепь Долга** (род как обязанность) // **Гробница Памяти** (ушедшие правят живыми)
- Друг → **Слияние** (теряет себя в любви) // **Тёплая Зависимость** (внешне отдельность, внутри — невозможность одиночества)

### Три глубинные дилеммы БЭ
1. **Слияние vs. Границы**
2. **Долг vs. Свобода Чувства**
3. **Вина vs. Невинность**

### Пять якорей БЭ
*отношение, близость, доверие, чувства, важность*

### Архетип-специфические глаголы
- **Дипломат:** соединяет, мостит, наводит, удерживает мир, переводит, выводит на разговор
- **Духовник:** слышит, принимает, выдерживает присутствие, узнаёт, не выносит приговор
- **Хранитель Рода:** несёт, помнит, передаёт, чтит, собирает, хранит, отпускает
- **Друг:** выбирает, остаётся, пускает, бережёт, разделяет, держит верность

## 5. Конкретные инструкции для следующей сессии

1. **Не пытайся читать в чат большие файлы построчно** — пользователь жаловался, что неудобно мотать. Читай в `Read` с лимитами или сразу пиши.

2. **Не пиши пробных кусков** — сразу финальный результат полным `Write`. Один файл за один раз. Перед записью продумай весь объём.

3. **Стиль из ЧИ-блоков (точные правила):**
   - Деловое изложение, без художественных метафор.
   - В «Вытеснении» — 2-4 предложения, с указанием на детский опыт.
   - В «Защите» — 2-4 названных механизма полужирным + расшифровка через тире.
   - В «Убеждениях» — 5-7 цитат в кавычках, прямая речь от первого лица.
   - В «Родовых программах» — 3-5 пунктов, **жирное имя программы** + тире + расшифровка.

4. **Для объединённых навыков** в подзаголовке указывать `*Грани: A + B + C*` (как в матрице навыков БЭ).

5. **Уникальность для БЭ:** избегать клише ЧИ-блоков (там про интеллектуализацию и «не задавай вопросов»). БЭ-блоки — про **связи, чувства, доверие, преданность**. Защиты — про слияние/дистанцию, идентификацию с агрессором, реактивное образование, парентификацию, эмоциональное замораживание.

6. **Сначала прочитай образцы:**
   - `Ne/блоки навыков ЧИ.md` целиком (формат)
   - `Si/блоки навыков БС.md` целиком (близкий регистр, тело)
   - `Fi/Навыки БЭ — [архетип].md` — для контента (Уровни 1-3 каждого навыка дают понимание, что именно вытесняется)

7. **Объём:** не экономить. Каждый из 58 навыков заслуживает 15-25 строк блоков. Итого ~1000-1200 строк.

8. **Порядок навыков** — точно как в `fi-tree.js` / `матрица навыков БЭ.md` (см. структуру в разделе 2 выше).
