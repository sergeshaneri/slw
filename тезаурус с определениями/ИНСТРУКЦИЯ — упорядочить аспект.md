# Инструкция: упорядочить аспект тезауруса + дополнить определениями

Используй этот промт для файлов: ЧИ, БИ, БЛ, ЧЛ, БЭ, ЧЭ, ЧС.  
Пример готового результата: `Белая Сенсорика (БС).md` в этой же папке.

---

## ПРОМТ (копировать целиком и отправить Клоду)

---

Прочитай файл `тезаурус с определениями/[АСПЕКТ].md` целиком.

Твоя задача — выполнить два шага подряд:

---

### ШАГ 1 — Упорядочить существующие определения по микрополям

**Структура файла:**

Файл состоит из двух частей:
- **Часть А — Список слов**: вверху файла, разбит на микрополя (МП) с заголовками `#### **Микрополе N: Название**`. После каждого заголовка — строка со словами через запятую.
- **Часть Б — Определения**: идёт после разделителя `---` и вводного текста. Содержит определения в произвольном порядке в двух форматах:
  - Буллет: `* **Слово:** Относится к [аспект], потому что...`
  - Нумерованный: `N. **Слово (описание):**\n   * **Связь с [аспект]:** ...`

**Алгоритм сопоставления — направление: слово → определение (не наоборот):**

Для каждого МП:
1. Возьми строку слов из этого МП.
2. Для каждого слова из строки — найди в Части Б то определение, заголовок которого наиболее точно соответствует этому слову.
3. Сопоставляя — игнорируй скобочный контент. Например, слово `Ощущение (телесное)` ищи как `Ощущение`. Слово `Уход (за телом, кожей)` ищи как `Уход`.
4. Одно определение может совпасть с несколькими словами (например, запись `Зуд / Щекотка` подходит и для слова `зуд`, и для слова `щекотка` — помести её под оба).
5. Сохраняй порядок слов из списка МП (не алфавитный, не произвольный — именно порядок из исходного списка).
6. Слова, для которых определение не найдено → отмечай отдельно (они будут закрыты на Шаге 2).
7. Определения, которые не подошли ни к одному слову ни в одном МП → раздел `## Определения вне списка` в конце файла.

**Результирующая структура файла:**

```
[Часть А — список слов — без изменений, дословно]

---

[Вводный текст — без изменений, дословно]

**Разбор Списка Слов для [аспект]:**

---

#### **Микрополе 1: Название**

[определения для слов МП1 в порядке слов из списка]
[для слов без определений — они будут добавлены на Шаге 2]

---

#### **Микрополе 2: Название**

[...]

---

## Определения вне списка

[определения, не нашедшие своё слово ни в одном МП]
```

**Важно:** не редактируй, не перефразируй и не сокращай существующие определения. Только переставляй их под правильные заголовки.

---

### ШАГ 2 — Написать определения для всех слов без них

После упорядочивания — для каждого слова из каждого МП, у которого нет определения, напиши новое определение прямо в том месте, где оно должно стоять по порядку слов.

**Формат записи:**
```
* **Слово:** Относится к [аспект], потому что *слово* – это [определение].
```

**Что обязательно должно быть в каждом определении:**

1. **Связь с ощущениями изнутри** — что именно человек чувствует внутри тела/психики, где это ощущается, как оно проявляется.
2. **Связь с потребностями** — какую потребность это слово отражает, удовлетворяет или нарушает.
3. **Связь с балансом / дисбалансом** — это состояние равновесия или сигнал о его нарушении?
4. **Опционально** — связь с удовольствием, наслаждением, наполнением или эстетикой, если уместно.

**Смысловое ядро аспекта** (через какую призму писать):

| Аспект | Ядро |
|--------|------|
| БС | Внутренние телесные ощущения, самочувствие, комфорт, физические потребности |
| ЧС | Воля, давление, захват пространства, интенсивность воздействия, сила |
| БИ | Внутреннее время, предчувствие, потенциал, интуиция процессов и состояний |
| ЧИ | Идеи, возможности, нестандартные связи, альтернативы |
| БЛ | Законы, логика, система, структура, доказательность |
| ЧЛ | Эффективность, технология, процессы, производительность, результат |
| БЭ | Отношения, симпатии, нравственность, эмоциональный климат, близость |
| ЧЭ | Эмоции, экспрессия, эмоциональное заражение, интенсивность переживания |

**Правила написания:**

- 2–3 предложения на определение.
- Не словарное определение — через призму аспекта.
- Никакого пафоса, мотивационного тона, абстрактных «высших смыслов».
- Конкретно: что именно ощущается, как это проявляется, к чему приводит.
- Если слово — **глагол** (есть, спать, трогать, чувствовать) — опиши как процесс и что происходит изнутри в этом процессе.
- Если слово — **существительное-качество** (мягкость, жёсткость, холод) — через ощущение этого качества.
- Если слово — **прилагательное** — через то, что это качество создаёт в восприятии изнутри.

**Пример хорошего определения (из файла БС):**

```
* **Дискомфорт:** Относится к БС, потому что *дискомфорт* – это внутреннее
ощущение физического неудобства, стеснения или раздражения, сигнализирующее
о неудовлетворённой потребности или нарушении телесного баланса. Ощущается
изнутри как «что-то не так» — давление, зуд, скованность или тягость,
которые требуют устранения.
```

```
* **Нежиться:** Относится к БС, потому что *нежиться* – это состояние
намеренного растворения в приятных телесных ощущениях — тепле, мягкости,
покое — без стремления куда-либо двигаться. Нежиться — значит полностью
довериться ощущениям изнутри и позволить телу насладиться состоянием
тёплого, расслабленного, сытого баланса.
```

---

### Итоговый результат

Перепиши файл `[АСПЕКТ].md` в новой структуре:
- Часть А (список слов) — без изменений
- Часть Б — определения расставлены по МП в порядке слов из списка
- У каждого слова из каждого МП есть своё определение
- Строк «Слова без определений» не остаётся
- В конце — раздел `## Определения вне списка`

Сверься с файлом `Белая Сенсорика (БС).md` в этой же папке как с примером готового результата.

---

## Как использовать

1. Замени `[АСПЕКТ]` на нужное имя файла (например, `Черная Интуиция (ЧИ)`)
2. Отправь промт Клоду с доступом к файловой системе
3. Клод прочитает файл, выполнит оба шага и перепишет его

**Порядок аспектов (рекомендуемый, от меньшего к большему):**
ЧЛ → БЛ → ЧЭ → БЭ → ЧС → ЧИ → БИ
