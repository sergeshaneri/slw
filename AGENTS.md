Настоящий корень репозитория — каталог с этим AGENTS.md; фронтенд расположен в slw-main/slw-main. Ветка задачи — codex/lite-local; база — c7f2b3c. У origin/main другая история, она не является базой этой работы.

Текущая авторизация: проверка main, создание локальной ветки, подготовка плана и harness. Код игры ещё не разрешён к реализации этим запросом. При последующем прямом указании реализовать план это ограничение снимается для согласованного объёма, повторное подтверждение не нужно.

Сохраняй посторонние изменения. Коммиты, push, deploy и смена ветки по умолчанию требуют отдельного указания. Не используй git add ., reset --hard, switch -C, clean, force-push.

Выполняй один этап плана за раз. Фиксируй фактические команды, результаты и ограничения в RUN_LOG.md. Ошибки заноси в ERRORS.md без секретов и личных данных. Не меняй тесты/критерии ради формального прохождения. Новый запрет требует наблюдаемого основания.
